# Phase 0 — Kotlin + Logic Fundamentals (Weeks 1–4)

**Goal:** Think in code without AI assist.  
**Rule:** Turn off Copilot/Cursor autocomplete for this entire phase.

## Before you start

1. Install Kotlin: `brew install kotlin`
2. Open `kotlin/phase0/` — work **in order**, one week at a time
3. Run each file: `cd kotlin/phase0 && ./run week1/01_VariablesAndTypes.kt`
4. **No copy-paste from AI** for drills — blank file practice is the point

## Weekly plan

| Week | Folder | Topics |
|------|--------|--------|
| **1** | `week1/` | Variables, control flow, functions, loops, null safety, data classes, sealed classes |
| **2** | `week2/` | Classes, interfaces, inheritance, extension functions |
| **3** | `week3/` | Collections **by hand** (no `filter`/`map` in drills), frequency, dedup, strings |
| **4** | `week4/` | Logic drills from scratch, recursion, **checkpoint** |

## Daily rhythm (suggested)

- **30–45 min** — read + run lesson file, type examples yourself once
- **30–45 min** — drills (`weekN-drills.kt` or `week4/Checkpoint.kt`) **from memory**
- **10 min** — explain yesterday’s solution out loud (no screen)

## Checkpoint (end of Week 4)

Can you write a function **from scratch**, no search, no autocomplete, in **under 10 minutes**?

Run: `./run week4/Checkpoint.kt` (practice mode)  
Criteria in `CHECKPOINT.md`

If not ready → repeat Week 3–4. **Do not start Phase 1 (DSA)** on shaky basics.

## After Phase 0

- Phase 1: `kotlin/arrays/`, `kotlin/hashing/`, … (6 weeks DSA)
- Phase 2+: Jetpack Compose (separate track later)

## File naming

- `01_…` → `07_…` = lessons (study + run)
- `weekN-drills.kt` = short exercises (try before opening solutions)
- `*Solutions.kt` = peek only after attempting
